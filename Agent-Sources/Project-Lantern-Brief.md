# Project Lantern — Project Brief

**Organisation:** Brindlewick Home Goods (fictional)
**Document owner:** Tom Okafor, Project Manager
**Version:** 1.0 (approved)
**Date:** 22 January 2027

---

## 1. Purpose
Replace Brindlewick's ageing order-management spreadsheets and legacy stock system with a single order-management system (OMS) supplied by Corvane Systems. The new system will handle retail and wholesale orders, stock levels and pick lists across both warehouses.

## 2. Objectives
- One system for orders and stock across Leeds and Bristol.
- Fewer manual re-keying errors between sales and warehouse teams.
- Real-time stock visibility for the wholesale team.

## 3. Scope
**In scope**
- Corvane OMS configuration for retail and wholesale orders.
- Migration of customer, product and open-order records from the legacy system.
- Rollout to the Leeds warehouse, followed by the Bristol warehouse.
- Training for warehouse, customer service and wholesale staff.

**Out of scope**
- Changes to the website or checkout.
- Finance and payroll systems.
