# Project Lantern — Status Update

**Date:** 5 February 2027
**Author:** Tom Okafor, Project Manager
**Reporting period:** 22 January – 5 February 2027
**Overall status:** Amber

---

## 1. Summary
Configuration finished on 31 January as planned. Data migration is behind: the latest test load had a high failure rate on customer records. Because of this, the Leeds go-live date is under review.

## 2. Data migration
The last test load failed on about **20% of customer records**. The main causes are duplicate customer accounts and missing or badly formatted postcodes in the legacy system. The team is cleaning the data and will run another test load once the fixes are in.

Corvane Systems has indicated that fixing the migration scripts will need extra consultant days beyond the original plan. Corvane has not yet given a figure, and no change request has been raised.

## 3. Go-live date
The Leeds go-live date is **under review**. A provisional date of **17 March 2027** is being considered, depending on the next test load. This date is not confirmed. Any change to the go-live date needs approval from the project sponsor.

## 4. Training
Leeds warehouse training is planned for late February. Bristol training has not been scheduled (see steering action 1, 29 January).

## 5. Budget
Spend to date is within budget. No contingency has been used yet.

## 6. Next steps
- Complete data cleansing and rerun the test load.
- Recommend a go-live date to the sponsor once the next test load results are in.
- Agree the Bristol training date.
